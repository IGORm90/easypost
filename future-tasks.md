# РАЗДЕЛ 2. Отложенные задачи

Кратко — название и строка контекста.

### AI

- **Генерация изображений** — по промпту, с учётом требуемого формата целевой сети
- **Генерация видео**
- **AI-агент в формате чата** — планирование постов и генерация медиа диалогом
- **MCP-сервер** — агент доступен извне как инструмент для других приложений
- **Автодополнение в редакторе** — подсказка продолжения по мере набора
- **Извлечение текста со страницы по URL** и превращение его в пост

### Автоматизации

- **Триггерные автоматизации** — авторепост и авто-промо по достижении порога лайков. Требует аналитики
- **Автопостинг из источника** — RSS, канал, лента

### Каналы

- YouTube, TikTok, Pinterest, VK, Tumblr, MeWe
- Kick, Twitch, Dribbble, Farcaster, Nostr, Lemmy, Skool, Whop
- Блоги: Medium, Dev.to, Hashnode, WordPress
- Рассылки: ListMonk, Moltbook
- Google My Business

### Биллинг и деньги

- **Реальный приём платежей** — эквайринг, рекуррентные списания, вебхуки платёжной системы
- **История счетов и чеки**
- **Отмена подписки и пропорциональный пересчёт при смене тарифа**
- **Партнёрская программа**
- **Кредиты на AI** как отдельная покупаемая сущность сверх тарифа

### Интеграции

- **Сторонние сервисы генерации медиа** — AI-аватары, готовые UGC-видео
- **OAuth-приложения (Approved Apps)** — если публичного API окажется мало
- **Расширение для браузера**

### Редактор и контент

- **Продвинутый редактор изображений** — кроп, фильтры, наложение текста
- **Опросы** — поддерживаются рядом сетей, требуют отдельного типа поста
- **Упоминания** — автодополнение по `@` с подгрузкой пользователей из целевой сети
- **Сокращение ссылок** — в коде уже помечено как post-MVP
- **Шаблоны постов**
- **Массовая загрузка постов из CSV**

### Мелочи интерфейса

- **Инвайт-ссылка клиенту на подключение канала** — агентский сценарий: клиент подключает свой аккаунт сам, не передавая доступы и не вступая в организацию
- **Настройки email-уведомлений в UI** — письма шлются, управлять ими нельзя
- **Формат даты и времени в настройках**
- **Напоминания о серии публикаций** — геймификация регулярности
- **Онбординг для пустого аккаунта**
- **Уведомления в интерфейсе** — колокольчик

### Инфраструктура

- **Экспорт данных организации**
- **Журнал действий (audit log)**
- **Двухфакторная аутентификация**
- **Больше локалей** — сейчас `en` и `ru`
- **Loki + Alloy + Grafana** — централизованные логи и алерты вместо Pulse/Log Viewer; план в `monitoring-plan-variant-1.md`
- **Внешний S3 вместо MinIO** — для медиа в production
- **Автовыкатка на push** — после нескольких успешных ручных релизов (`workflow_dispatch`)
- **Staging-среда** — отдельный Compose-проект с своими БД и bucket
